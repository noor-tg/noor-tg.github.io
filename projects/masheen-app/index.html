نظرة عامة

ماشين تطبيق ويب أعيد بناء واجهته البرمجية ولوحة التحكم والموقع الرئيسي له، وصُيِّن مع فريق المشروع لمدة ثلاث سنوات.

التحدي

كانت الواجهة البرمجية صعبة الصيانة، وتشغل لوحة التحكم على Vue 2 مع webpack، ولم يكن للموقع الرئيسي طريقة لمشاركة الطلبات إلى مواقع التواصل الاجتماعي.

الحل

أعيد بناء الواجهة البرمجية على أحدث نسخ Node.js مع TypeScript، وأُضيف توثيق كامل عبر OpenAPI مع واجهة تفاعلية عبر Swagger UI (متوافقة مع Postman) واختبارات تكامل كاملة للواجهة البرمجية. نُقلت لوحة التحكم من Vue 2 إلى Vue 3 باستخدام Vite بدلاً من webpack، مع إضافة خواص جديدة وصيانة الأجزاء القديمة. أُضيفت آلية مشاركة الطلبات إلى مواقع التواصل الاجتماعي على الموقع الرئيسي (masheenn.com). نُشر المشروع على خادم VPS Linux مع نسخ احتياطية ومراقبة النظام والدعم الفني.

النتائج

  • أعيد بناء الواجهة البرمجية على Node.js + TypeScript مع توثيق OpenAPI/Swagger واختبارات تكامل.
  • نُقلت لوحة التحكم من Vue 2 إلى Vue 3 باستخدام Vite.
  • أصبح الموقع الرئيسي قادرًا على مشاركة الطلبات إلى مواقع التواصل الاجتماعي.
  • نُشر على خادم VPS Linux مع نسخ احتياطية ومراقبة ودعم فني.
