Overview

A desktop point-of-sale management program with items, sales, expenses, multiple users, reports and charts. It can run as a desktop app, be hosted on a local server for use across multiple devices on a local network, or be published online and accessed from anywhere.

The challenge

A business needed a point-of-sale system that works both offline on a local network and online, with desktop and multi-user support.

The solution

Built with Electron.js, Vue, TypeScript and Node.js with Express, using SQLite for local data and Socket IO for real-time sync, styled with Tailwind CSS. Any part of the program can be adjusted to fit the required project.

Results

  • Desktop POS app with items, sales, expenses, users, reports and charts.
  • Runs offline on a local network or online from anywhere.
  • Multi-user support with role-based access.
  • Built with Electron + Vue + Node.js/Express + SQLite.
