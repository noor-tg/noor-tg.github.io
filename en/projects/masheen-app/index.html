Overview

Machine is a web application whose API, control panel and main site I rebuilt and maintained alongside the project team for three years.

The challenge

The API was hard to maintain, the control panel ran on Vue 2 with webpack, and the main site had no way to share requests to social media.

The solution

Rebuilt the API on the latest Node.js with TypeScript, added full OpenAPI documentation with an interactive Swagger UI (Postman-compatible) and complete API integration tests. Migrated the control panel from Vue 2 to Vue 3 with Vite instead of webpack, added new features and maintained older parts. Added a request-sharing mechanism to social media on the main site (masheenn.com). Deployed to a Linux VPS with backups, system monitoring and technical support.

Results

  • API rebuilt on Node.js + TypeScript with OpenAPI/Swagger docs and integration tests.
  • Control panel migrated from Vue 2 to Vue 3 with Vite.
  • Main site can share requests to social media.
  • Deployed on a Linux VPS with backups, monitoring and support.
