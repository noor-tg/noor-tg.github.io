Overview

Shipit turns a git push into a running service on your own Linux servers, with no dashboard to babysit.

The challenge

Small teams wanted the comfort of a platform without its bill or its lock-in.

The solution

A single Rust binary builds a Docker image, starts it beside the old one and switches traffic once health checks pass. Rollback is one command.

Results

  • Used in production by about 200 companies.
  • Contributors from more than twenty countries.
  • Docs and install script maintained for Ubuntu, Debian and Arch.
