نظرة عامة

ماشين تطبيق ويب أعيد بناء واجهته البرمجية ولوحة التحكم والموقع الرئيسي له، وصُيِّن مع فريق المشروع لمدة ثلاث سنوات.

أبرز الإنجازات

  • أعيد بناء الواجهة البرمجية على Node.js + TypeScript مع توثيق OpenAPI/Swagger واختبارات تكامل للواجهة البرمجية.
  • نُقلت لوحة التحكم من Vue 2 إلى Vue 3 باستخدام Vite بدلاً من webpack.
  • أُضيفت آلية مشاركة الطلبات إلى مواقع التواصل الاجتماعي على الموقع الرئيسي (masheenn.com).
  • نُشر المشروع على خادم VPS Linux مع نسخ احتياطية ومراقبة النظام والدعم الفني.

التقنيات

  • Node.js
  • TypeScript
  • Vue 3
  • MySQL
  • Redis
