تطبيقات تعمل دون اتصال بلا عناء

نمط عملي لمزامنة التعديلات باستخدام SQLite مأخوذ من تطبيق روم.

يبدو العمل دون اتصال ميزة، لكنه في الحقيقة قرار بشأن مكان وجود الحقيقة. في روم الحقيقة على الهاتف، والخادم نسخة احتياطية ممتازة فقط.

احفظ العمليات لا الحالات

بدلًا من حفظ آخر نسخة من الرحلة نحفظ ما فعله الشخص: إضافة محطة أو نقلها أو إعادة تسمية يوم. وعند عودة الاتصال يعيد الهاتف هذه القائمة ويدمج الخادم القوائم من كل الأجهزة.

CREATE TABLE ops (
  id TEXT PRIMARY KEY,
  kind TEXT NOT NULL,
  payload JSON NOT NULL,
  created_at INTEGER NOT NULL,
  synced INTEGER DEFAULT 0
);

اجعل التعارضات مملة

أغلب التعارضات سببها شخصان يغيّران أشياء مختلفة، ودمج العمليات يزيلها. وللقليل الحقيقي منها نعرض النسختين ونترك الاختيار للشخص، فالسؤال الواضح أفضل من التخمين الذكي.
